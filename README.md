## 📋 Syllabus & List of Experiments

| Expt. No. | Official Experiment Title | Technology Stack |
| :---: | :--- | :--- |
| **1** | Design a Registration Form using HTML5 and CSS3 on the Selected Problem Statement | HTML5 Semantic Elements, CSS3 Flexbox/Grid, Form Validation API |
| **2** | Write a Program to Create and Build a Password Strength Indicator and Star Rating System using jQuery | HTML5, CSS3, JavaScript, jQuery DOM & Event Handling |
| **3** | Design a Homepage using React.js | React.js (Components, Props, Hooks), Modern Responsive UI |
| **4** | Create a Simple Login Form using React.js | React.js (`useState`, Controlled Inputs, Form Validation, Auth Simulation) |
| **5** | Connecting Your React.js Project with MongoDB | MERN Stack (React.js Frontend, Node.js + Express.js REST API, MongoDB + Mongoose) |
| **6** | Design a Web Page using Node.js | Pure Node.js (`http`, `fs`, `path`, `url` core modules, Routing, Server Metrics) |
| **7** | Design a Form Using Express.js in Node.js | Express.js, Body Parser Middleware, Server-side Validation, Template/Dynamic Response |
| **8** | Integration of Third-Party Services in Web Application (SMS Gateway, Payment Gateway, Email) | Node.js, Express, Nodemailer (Email), Twilio (SMS), Razorpay / Stripe (Payment Gateway) |
| **9** | Hosting the Website with Domain Registration Process | DNS Architecture, TLDs, Registrar Workflow, Vercel / Netlify / Render / GitHub Pages Deployments |
| **10** | Integration of SSL Certificate in Web Application | PKI & TLS/SSL Architecture, OpenSSL Self-Signed Certs, Node.js HTTPS Server, Nginx Reverse Proxy |
